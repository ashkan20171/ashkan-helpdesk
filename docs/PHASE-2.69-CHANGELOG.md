# Phase 2.69 — Advanced AI Copilot & Intelligent HelpDesk Assistant

## هدف
افزودن لایه Copilot هوشمند به Ashkan HelpDesk برای کمک به کارشناس، مدیر و مشتری.

## قابلیت‌ها
- Copilot کارشناس، مدیر و مشتری
- تحلیل Ticket، Knowledge Base، SLA، Customer Health، Asset و Workflow
- Insight Center با Confidence Score و Impact
- پیشنهاد Next Best Action
- تشخیص ریسک SLA و Customer Health
- پیشنهاد مقاله مناسب Knowledge Base
- تشخیص ارتباط Ticket و Asset
- پیشنهاد بهینه‌سازی Workflow
- گفت‌وگوی AI-ready با Context
- Inspector برای بررسی انسانی پیشنهادهای AI
- حالت AI-ready بدون اجرای خودکار Actionهای مخرب
- UI کاملاً RTL و responsive
- مسیر `/copilot`
