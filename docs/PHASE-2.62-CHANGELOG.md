# Phase 2.62 — Advanced Identity, Profile & Organization Access Center
پروفایل شخصی و سازمانی، تغییر رمز، MFA، نشست‌ها، اعضای سازمان، نقش‌ها و Permission snapshot اضافه شد. RBAC جدید شامل `profile.manage`، `security.manage` و `organization.members.manage` است. احراز هویت واقعی، JWT/Refresh Token، Hash رمز، MFA secret و دعوت‌نامه در Backend ASP.NET Core + PostgreSQL پیاده‌سازی می‌شود.
